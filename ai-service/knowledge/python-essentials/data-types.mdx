## What Is a Data Type?

A **data type** defines the classification of a value. It tells Python what operations can be carried out on that data:

```python
name = "Emma"       # str (String)
age = 22            # int (Integer)
height = 165.5      # float (Floating-point)
is_student = True   # bool (Boolean)
```

Each variable above stores a fundamentally distinct class of information.


## The Four Core Primitive Data Types

| Data Type | Formal Name | Description | Practical Example |
| :--- | :--- | :--- | :--- |
| **`str`** | String | Textual characters wrapped in matching quotes | `"Emma"`, `'Data Science'` |
| **`int`** | Integer | Whole numbers without any decimal portion | `22`, `-5`, `1000` |
| **`float`** | Floating-Point | Decimal approximations and fractional numbers | `165.5`, `3.14159`, `0.0` |
| **`bool`** | Boolean | Binary logical truth values (`True` or `False`) | `True`, `False` |


## Deep-Dive into Each Type

### 1. Strings (`str`)
Strings store text. In Python, you can enclose strings in either single quotes (`'...'`) or double quotes (`"..."`):
```python
course = "Data Visualization"
print(course)
```
```text
Data Visualization
```
<InfoCallout title="Quotation Marks Matter" variant="warning">
Without quotation marks, Python thinks you are referring to a variable name. <code>course = Data</code> causes a <code>NameError</code> unless a variable named <code>Data</code> already exists.
</InfoCallout>

### 2. Integers (`int`)
Integers represent whole numbers—both positive and negative—with no decimal places. They are ideal for counting items, measuring years, or indexing records:
```python
students_count = 45
print(students_count)
```

### 3. Floating-Point Numbers (`float`)
Floats represent real numbers containing decimal points. Use them whenever precision is required, such as calculating grade point averages, percentages, and sensor readings:
```python
temperature = 98.6
print(temperature)
```

### 4. Booleans (`bool`)
Booleans contain only one of two possible states: `True` or `False`. They power conditional logic, filtering, and decision-making in your algorithms:
```python
is_registered = True
print(is_registered)
```


## Inspecting Types with `type()`

When writing complex programs or importing datasets, you will often need to confirm how Python interprets a specific variable. Python provides the built-in `type()` function:

```python
name = "Emma"
age = 22
gpa = 3.8
graduated = False

print(type(name))       # Output: <class 'str'>
print(type(age))        # Output: <class 'int'>
print(type(gpa))        # Output: <class 'float'>
print(type(graduated))  # Output: <class 'bool'>
```

## Common Mistakes & How to Avoid Them

### 1. Treating Numbers as Text
Putting quotes around a number turns it into a string. You cannot perform mathematical operations on strings:
```python
# Incorrect: Treated as text
age = "21"
# age + 1  --> TypeError: can only concatenate str (not "int") to str

# Correct: Treated as an integer
age = 21
print(age + 1)  # 22
```

### 2. Lowercase Boolean Keywords
Python is strictly case-sensitive. `True` and `False` must always begin with a capital letter:
```python
# Incorrect: NameError
is_valid = true

# Correct
is_valid = True
```
