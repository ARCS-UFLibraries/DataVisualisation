## What Is a Bar Chart?

A bar chart displays numerical values across distinct categories using proportional rectangular bars. Typically:
* The **horizontal axis (x-axis)** displays the categorical groups (e.g., Male vs. Female, or education levels).
* The **vertical axis (y-axis)** displays the measurement or count (e.g., Average Math Score).

## When Should You Use a Bar Chart?

Use a bar chart whenever you are comparing values across **discrete, categorical groups**. 

Common examples from data science and business:
* **Average exam scores by gender** or test preparation status
* **Student distribution** across lunch programs or majors
* **Sales volume** broken down by product category or region
* **Customer satisfaction scores** across branches

<InfoCallout title="Chart Decision Rule" variant="tip">
If your independent variable consists of separate categories (like departments or degrees), use a <strong>bar chart</strong>. If your data tracks continuous change over time (like daily stock prices or monthly temperatures), use a <strong>line chart</strong>.
</InfoCallout>

## Your First Bar Chart

Let’s create a foundational bar chart with Matplotlib comparing math scores between two groups:

```python
import matplotlib.pyplot as plt

categories = ["Female", "Male"]
values = [63.6, 68.7]

plt.bar(categories, values)
plt.show()
```

In just a few lines, Matplotlib draws two bars where the vertical height represents the average score of each group.

## Professional Labeling & Styling

Unlabeled charts confuse readers. Professional charts always include an informative title and labeled axes with units of measurement:

```python
import matplotlib.pyplot as plt

categories = ["Female", "Male"]
values = [63.6, 68.7]

# Styling bars with university brand colors
plt.bar(categories, values, color=["#0021A5", "#FA4616"], width=0.6)
plt.title("Average Mathematics Score by Gender", fontsize=14, fontweight="bold", pad=12)
plt.xlabel("Gender Group", fontsize=11)
plt.ylabel("Average Mathematics Score (out of 100)", fontsize=11)
plt.ylim(0, 80) # Setting a consistent baseline
plt.show()
```

## Handling Multi-Category Charts & Long Labels

When comparing multiple categories—such as six levels of parental education—labels can overlap. Matplotlib allows you to rotate tick labels and widen the figure size for optimal readability:

```python
import matplotlib.pyplot as plt

education_levels = [
    "Some High School", "High School", "Some College",
    "Associate's", "Bachelor's", "Master's"
]
avg_writing_scores = [63.5, 66.0, 68.2, 69.9, 73.1, 75.4]

plt.figure(figsize=(10, 5))
bars = plt.bar(education_levels, avg_writing_scores, color="#0021A5")
plt.title("Average Writing Score by Parental Education Level", fontsize=13, fontweight="bold")
plt.xlabel("Parental Education Level")
plt.ylabel("Average Writing Score")
plt.xticks(rotation=30, ha="right")

# Direct value labels on top of bars
plt.bar_label(bars, fmt="%.1f", padding=3)
plt.ylim(0, 85)
plt.tight_layout()
plt.show()
```

## Common Mistakes & Troubleshooting

### 1. Using a Bar Chart for Continuous Time Series
Bar charts can be used for time periods (like quarterly revenue), but if data has dozens of continuous points, a **line chart** provides a far clearer visual flow.

### 2. Truncating the Baseline (The Zero-Axis Rule)
Always start your vertical axis at **0** when using bar charts. Because human eyes judge the *area and height* of the bar, zooming in on the top can artificially exaggerate tiny differences and mislead your audience.

### 3. Forgetting Axis Units
Writing `Score` is good, but `Average Math Score (0–100)` removes all ambiguity.
